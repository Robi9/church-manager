# Project conventions

## Language

- Write all code and documentation in English, including identifiers, comments,
  docstrings, technical logs, commit messages, and pull request descriptions.
- Write all frontend text visible to end users in Brazilian Portuguese (pt-BR),
  including navigation, labels, buttons, placeholders, tooltips, accessibility
  labels, validation messages, error messages, notifications, and empty states.
- Backend messages displayed in the frontend must also be in Brazilian
  Portuguese. Keep internal technical messages in English and translate them
  before presenting them to users.
- Preserve API field names, database identifiers, and other machine-readable
  contracts in English. User-facing strings are an explicit exception to the
  English-only code convention.
- Apply these conventions to new work and changes to existing content.
